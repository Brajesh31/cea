# 📓 Optional Jupyter Notebooks

This repository's supported interactive entry points remain the three Streamlit scripts at the root. Notebooks are optional companion material for step-by-step exploration and do not replace the canonical source.

## Recommended notebook practices
- Keep all datasets synthetic.
- Record Python and package versions.
- Use fixed random seeds for reproducible demonstrations.
- Explain array dimensions and algorithm assumptions.
- Clear notebook outputs before committing if they contain machine-specific paths or sensitive information.
- Do not commit large generated outputs.

No notebook runtime is required to run the Streamlit apps.
