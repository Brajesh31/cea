# 🧪 Example Data

This folder contains small synthetic fixtures used for learning, manual checks and tests.

- `candidate_examples.csv`: sample weather-style attributes and labels.
- `backprop_inputs.csv`: tiny numeric input rows for shape demonstrations.
- `baseline_labels.csv`: a tiny class sequence for majority-baseline exercises.

All example values are synthetic. They do not represent real people, organizations or operational datasets.
