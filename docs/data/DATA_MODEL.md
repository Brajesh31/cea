# 🗃️ Data and Persistence Model

The project has no application database, ORM, durable model storage or backend API.

| Demo | Data source | Persistence |
|---|---|---|
| CEA.py | User-entered text examples | No application database/file persistence |
| bpalgo.py | User-entered values and fixed target | Network initialized in process on rerun |
| id3.py | Generated NumPy arrays and pandas DataFrame | Runtime generated data |

Any future storage requires a documented purpose, owner, access model, minimization, encryption, retention, deletion and backup policy before implementation. Fixtures and screenshots must use synthetic data.
