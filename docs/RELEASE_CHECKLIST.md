# ✅ Release Checklist

- [ ] README/docs describe actual code.
- [ ] Python and dependencies recorded.
- [ ] Compilation passes.
- [ ] Pytest passes on candidate commit.
- [ ] All intended Streamlit entry points start.
- [ ] Synthetic smoke checks performed.
- [ ] Algorithm limitations visible.
- [ ] No secrets, private data or generated environments committed.
- [ ] Dependency alerts reviewed.
- [ ] Hosting access/data handling reviewed.
- [ ] Changelog/release notes updated.
- [ ] Rollback revision recorded.

A green CI run does not establish mathematical correctness or production suitability.
