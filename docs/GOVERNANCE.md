# 🏛️ Project Governance

## Scope
A small educational collection of three independent Streamlit scripts, not a production ML platform.

## Decisions
Changes should be proposed through issues or pull requests. Maintainers review scope, algorithm correctness, safety, tests and documentation before merging.

## Technical decisions
Significant changes to algorithm definitions, data collection, persistent state, dependencies or deployment should be recorded using an ADR template.

## Release authority
The repository maintainer approves releases and verifies that documented behavior and limitations are accurate.

## Community
Contributors follow the Code of Conduct. Security vulnerabilities are reported through the private channel described by SECURITY.md.
