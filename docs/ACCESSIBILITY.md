# ♿ Accessibility Guidance

The applications use Streamlit widgets. That does not prove WCAG conformance.

## Authoring rules
- Give each input an unambiguous label and clear instructions.
- Use descriptive headings and concise explanations.
- Never communicate status through color alone.
- Keep tables and arrays understandable at zoom and narrow widths.
- Provide text explanations for visual/numerical outputs.

## Manual checks
| Area | Check |
|---|---|
| Keyboard | Every widget is reachable and operable |
| Focus | Order is logical and visible |
| Labels | Assistive technology announces each widget's purpose |
| Errors | Invalid input is explained in text |
| Contrast | Text and controls remain perceivable |
| Zoom | Page remains usable at 200% |
| Tables | Headers and values are understandable |

This is a review guide, not an audit or certification. Record findings in the accessibility review template.
