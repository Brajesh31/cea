## Accuracy policy
Never describe the current ID3 demo as a decision tree. Never describe displayed majority-class accuracy as a held-out metric. Never claim the neural network retains training across reruns. Never call CEA's simplified update a validated full Candidate Elimination implementation. Update this hub whenever files move.
