# ✅ Quality Gates

## Pull request
- [ ] Change is scoped and explained.
- [ ] Algorithm claims match implementation.
- [ ] New/changed functions have tests.
- [ ] Input and numerical edge cases considered.
- [ ] No private data, secrets or generated environments committed.
- [ ] Dependencies justified and reviewed.
- [ ] Docs, examples and diagrams updated.
- [ ] CI passes on exact commit.

## Release
- [ ] Runtime and dependency versions documented.
- [ ] All three app entry points smoke-tested.
- [ ] Limitations and intended audience displayed clearly.
- [ ] Hosting access and retention reviewed.
- [ ] Deployment commit and rollback revision recorded.

## Not production readiness criteria
A passing pytest suite or Streamlit startup does not make these demos valid models, secure multi-user products or suitable high-impact decision systems.
