# 🔐 Security Checklist

- [ ] Use synthetic examples only.
- [ ] Review hosting access before sharing a URL.
- [ ] Bound row counts, line lengths and numeric ranges.
- [ ] Handle parse and shape errors without raw tracebacks.
- [ ] Do not add secrets to source control.
- [ ] Keep Streamlit secret files ignored.
- [ ] Review direct/transitive dependencies.
- [ ] Avoid unnecessary filesystem access and uploads.
- [ ] Review host logs, backups and retention.
- [ ] Clearly label toy-model limitations.
- [ ] Never use outputs for high-impact decisions.
- [ ] Reassess threats when network or persistence is introduced.

Record evidence for each checked item. This is not a security certification.
