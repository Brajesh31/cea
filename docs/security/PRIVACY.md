# 🔒 Privacy and Data Handling

Current scripts accept sample values through Streamlit widgets or generate synthetic data. They do not implement an application database or intentionally call external APIs. Streamlit sessions and host-level logs/backups may still process operational data.

Use invented samples only. Do not enter names, addresses, IDs, health, financial or employment records. Do not publish screenshots containing private values. Review hosting provider data handling before deployment. Do not promise zero retention or deletion without reviewing host behavior. If persistence is added, define purpose, access, retention and deletion before collecting data.
