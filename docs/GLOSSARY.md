# 📖 Glossary

| Term | Meaning |
|---|---|
| Candidate Elimination | Concept-learning algorithm maintaining consistent specific and general hypothesis boundaries |
| Hypothesis | Candidate mapping from attributes to a class |
| Version space | Hypotheses consistent with observed training examples |
| Specific boundary | Maximally specific consistent hypotheses under a chosen ordering |
| General boundary | Maximally general consistent hypotheses under a chosen ordering |
| Sigmoid | Logistic activation mapping real values into (0,1) |
| Weight | Trainable coefficient in an affine transformation |
| Bias | Trainable offset added to an affine transformation |
| Forward pass | Calculation mapping inputs to outputs |
| Backpropagation | Chain-rule-based gradient calculation |
| Gradient descent | Parameter update using a loss gradient |
| Dummy classifier | Baseline that ignores input features |
| Majority-class baseline | Dummy classifier predicting the most frequent training label |
| In-sample score | Metric calculated on data also used for fitting/selection |
| Data leakage | Evaluation information influencing fitting or selection |
| Synthetic data | Artificially generated data, not real-person records |
| Streamlit rerun | Script re-execution after widget interaction |
| Reproducibility | Recreating results with recorded code, data, environment and seeds |
