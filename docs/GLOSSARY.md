# 📖 Glossary

| Term | Meaning |
|---|---|
| Candidate Elimination | Concept-learning algorithm that maintains consistent specific and general hypothesis boundaries |
| Hypothesis | Candidate mapping from attributes to a class |
| Version space | Hypotheses consistent with observed training examples |
| Specific boundary | Maximally specific consistent hypotheses under the chosen ordering |
| General boundary | Maximally general consistent hypotheses under the chosen ordering |
| Sigmoid | Logistic activation function mapping real values into (0,1) |
| Weight | Trainable coefficient in an affine neural-network transformation |
| Bias | Trainable offset added to an affine transformation |
| Forward pass | Calculation that maps inputs to model outputs |
| Backpropagation | Chain-rule-based gradient calculation through a computational graph |
| Gradient descent | Parameter update using a loss gradient |
| Dummy classifier | Simple baseline that ignores input features |
| Majority-class baseline | Dummy classifier always predicting the most frequent training label |
| In-sample score | Metric calculated using data also used to fit/select the model |
| Data leakage | Information from evaluation data influencing model fitting or selection |
| Synthetic data | Artificially generated data rather than direct records of real people |
| Streamlit rerun | Re-execution of a Streamlit script after widget interaction |
| Reproducibility | Ability to recreate results with recorded code, data, environment and random seeds |
