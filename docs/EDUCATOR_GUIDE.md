# 👩‍🏫 Educator Guide

Use these pages to teach hypothesis updates, matrix dimensions and sigmoid activation, dummy baselines, and data leakage. Keep examples synthetic and explain that outputs are unsuitable for high-impact decisions.

Suggested prompts: identify invalid inputs; derive a small case by hand; inspect tensor shapes; explain why constant predictions can achieve non-zero accuracy; design a valid held-out evaluation. Current CEA is simplified and id3.py is not an ID3 tree, so present these as code-review opportunities.
