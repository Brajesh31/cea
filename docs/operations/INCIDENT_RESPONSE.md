# 🚨 Incident Response

1. Identify affected entry point, host and source commit.
2. Restrict or disable access if users may be harmed or data exposed.
3. Preserve host logs and evidence securely.
4. Separate confirmed facts from assumptions.
5. Rotate exposed credentials through provider-supported procedures.
6. Review dependencies, deployment and source changes.
7. Restore a known-good revision or keep the app disabled.
8. Verify all demos independently if shared dependencies changed.
9. Record timeline, impact and corrective actions.
10. Update docs and tests.

Never paste secrets or private input into public issues.
