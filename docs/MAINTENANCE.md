# 🛠️ Maintenance Guide

## Routine maintenance
- Review dependency update pull requests.
- Check CI and CodeQL alerts after changes.
- Confirm README commands and paths match the tree.
- Re-run all apps after shared dependency updates.
- Review algorithm claims whenever implementation changes.
- Update examples, diagrams, templates and changelog.

## Dependency maintenance
Check Python compatibility, Streamlit behavior, NumPy numerical behavior and pandas API changes. Test from a clean virtual environment.

## Content maintenance
Remove stale screenshots, package versions and unverified claims. Distinguish implemented behavior from proposals.

## Ownership
The maintainer prioritizes issues, reviews releases and keeps security reporting instructions current.
